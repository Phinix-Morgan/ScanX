# ScanX - QR Code Generator

ScanX is a responsive QR Code Generator built using HTML, CSS, and JavaScript. It allows users to instantly generate QR codes for text or URLs using an external QR Code API through a clean and user-friendly interface.

Check it out : https://phinix-morgan.github.io/ScanX/

## Features

- Generate QR codes instantly from text or URLs.
- Responsive and modern user interface.
- Automatically displays the generated QR code.
- Supports any text, website URL, or simple data input.
- Dedicated About page describing the project.
- Social media links integrated into the interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- QR Code Generator API
- Font Awesome

## Project Structure

- `index.html` – Main QR Code Generator interface.
- `about.html` – Information about the project.
- `index.js` – Handles QR code generation and user interactions.
- `styles.css` – Main application styling.
- `style.css` – About page styling.

## How It Works

1. Enter any text or URL.
2. Click **Generate QR Code**.
3. The application sends the input to the QR Code API.
4. The generated QR code is displayed instantly.
5. Entering new data generates a new QR code.

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Phinix-Morgan/ScanX.git
cd ScanX
```

### Run the project

Open `index.html` in your preferred web browser.

No installation or additional dependencies are required.

## API Used

This project uses the free QR Code Generator API to generate QR code images dynamically.
